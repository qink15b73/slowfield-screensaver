# Ulam Prime Field Screensaver

一个**纯 Rust 优先**实现的 Windows `.scr` 屏保：用乌拉姆螺旋把素数映射到二维平面，并以缓慢生长的点阵呈现素数中的对角线结构。运行时不需要 C/C++ 主程序、着色器文件或外部素材。

## 视觉与动画规则

- 从中心的 `1` 开始，按自然数顺序向外展开乌拉姆螺旋；只有素数会亮起。
- 新数字以**恒定的数字/格子速率**出现，因此螺旋每一条边的点亮速度一致；单幕用 4 分钟缓慢展开，刚出现的素数会短暂增强亮度与光晕。实现使用时间到位置的直接映射，不会因为某一帧变慢而积累补帧任务。
- 画布半径固定，并在上下左右预留约 8% 的安全边距，最外圈与点光晕不会贴边或被裁切。缩放遵循乌拉姆图自身的几何规律：边长为 `s` 的奇数方块正好容纳 `s²` 个自然数，因此当前内容的半边长是 `√n / 2`（`n` 为自然数游标）。相机半幅直接取 `√n / 2`，缩放为画布半径除以相机半幅，画面按 `1/√n` 平滑收缩。该曲线只跟自然数递增有关，与素数数量无关，也没有逐圈目标、缓动追赶或边界钳制。动画计时器同时提升到 1 ms 精度，避免 Windows 默认 15.6 ms 定时器粒度造成的抖动。
- 每幕最大只生成 `251×251`、`301×301`、`351×351` 或 `401×401` 的有限网格；4 分钟展开、7 秒停留后重开新幕。因此点数、内存、每帧绘制量都受到上限约束。
- 每幕随机选择**方形**或**圆形**裁切的乌拉姆图，并轮换配色。圆形模式遵循自己的内切圆律：取当前展开正方形 `[-√n/2, √n/2]²` 的内切圆，半径 `r = √n/2`，面积 `πr² = πn/4`，即始终是方形面积的约 78.5%。它与方形共用同一条展开前沿和缩放曲线，但面积常数不同；不能改用 `n = πr²` 的面积等式，因为那会让圆半径比方形半边长约 12.8%，圆的上下左右伸出已生成的格点范围，边缘出现空带，形状退化为圆角方形。圆形模式只显示当前内切圆内的点。

## Windows 屏保模式

```text
ulam.scr /s        全屏屏保
ulam.scr /p <HWND> 控制面板预览
ulam.scr /c        简介对话框
ulam.scr /w        可缩放窗口预览（开发时推荐）
ulam.scr /d        全屏调试路径
```

全屏模式下，键盘、鼠标按键或明显鼠标移动会关闭屏保。

## 构建

要求：Windows 与 Rust stable（已验证于 `x86_64-pc-windows-msvc`）。`windows-sys` 是唯一第三方依赖，用于 Win32 和传统 OpenGL FFI。

```bat
build.bat
```

产物：`bin\ulam.scr`

开发预览：

```bat
bin\ulam.scr /w
```

安装时可将 `.scr` 放入 Windows 屏保选择器识别的位置（例如管理员权限下的 `%SYSTEMROOT%\System32`），再从系统的“屏幕保护程序”设置中选择它。

## 验证

```bat
cargo test
cargo build --release
```

单元测试覆盖乌拉姆螺旋的首圈坐标和素数筛选的基本行为。
